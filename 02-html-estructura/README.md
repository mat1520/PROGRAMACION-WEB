# HTML – Estructura de la web

HTML es el lenguaje de marcado que define la estructura básica de una página web. No es programación, sino el esqueleto sobre el que se construye todo lo demás.

## Estructura básica de un documento HTML
- `<!DOCTYPE html>`: Indica que el documento es HTML5.
- `<html>`: Elemento raíz de la página.
- `<head>`: Contiene metadatos, título y enlaces a recursos.
- `<body>`: Contiene el contenido visible de la página.

## Etiquetas importantes
- `h1`–`h6`: Encabezados de diferentes niveles.
- `p`: Párrafo de texto.
- `a`: Enlace a otra página o recurso.
- `img`: Imagen.
- `ul`, `ol`, `li`: Listas desordenadas, ordenadas y sus elementos.
- `div`: Contenedor genérico para agrupar contenido.
- `span`: Contenedor en línea para agrupar texto.
- `form`: Formulario para enviar datos.
- `input`: Campo de entrada de datos.
- `button`: Botón.

## Atributos comunes
- `id`: Identificador único para un elemento.
- `class`: Clase para agrupar y aplicar estilos.
- `src`: Fuente de una imagen o recurso.
- `href`: Destino de un enlace.

Crea una página web simple usando solo HTML, practicando la estructura y las etiquetas mencionadas.
