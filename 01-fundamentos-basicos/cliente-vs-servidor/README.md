# Cliente vs Servidor

- **Cliente:** Es el dispositivo o programa que solicita información o servicios (por ejemplo, tu navegador web).
- **Servidor:** Es el dispositivo o programa que responde a esas solicitudes (por ejemplo, el servidor donde está alojada una página web).

## Ejemplo sencillo
Cuando visitas una página web:
1. El cliente (tu navegador) pide la página.
2. El servidor la envía de vuelta al cliente.
