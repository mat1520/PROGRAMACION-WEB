# ¿Qué es una URL? ¿Qué son HTTP y HTTPS?

- **URL:** Es la dirección única de una página o recurso en Internet (por ejemplo, https://www.ejemplo.com).
- **HTTP:** Protocolo que permite la transferencia de información en la web.
- **HTTPS:** Es como HTTP, pero añade seguridad cifrando la información.

## Ejemplo sencillo
- URL: https://www.ejemplo.com
- HTTP: http://www.ejemplo.com (sin cifrado)
- HTTPS: https://www.ejemplo.com (con cifrado)
